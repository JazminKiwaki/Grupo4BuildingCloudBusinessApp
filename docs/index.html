Introducción

El presente proyecto tiene como objetivo desarrollar una solución integral basada en herramientas de Microsoft Azure y Power Platform para la empresa “Mundo de Patas”. La propuesta busca modernizar los procesos de gestión de información, garantizar una adecuada explotación de los datos y proporcionar un soporte sólido para la toma de decisiones estratégicas.

Sobre Mundo de Patas

Mundo de Patas es un e-commerce dedicado a la comercialización de productos para mascotas. El crecimiento del negocio generó la necesidad de fortalecer la captura, administración y análisis de la información operativa y comercial para mejorar la experiencia del cliente y la eficiencia interna.

Objetivos del Proyecto

  • Implementar una solución end-to-end de captura, procesamiento, almacenamiento y visualización de datos.
  • Mejorar trazabilidad y control operativo de clientes, productos y ventas.
  • Proveer dashboards en tiempo real para apoyar la toma de decisiones.
  • Garantizar escalabilidad y seguridad en la infraestructura cloud.

Diagrama de Arquitectura

La arquitectura se organiza en capas que cubren desde la adquisición de datos hasta su presentación analítica. Se utiliza la combinación de Azure y Power Platform para asegurar integración, procesamiento y visualización eficaces.

Data Sources: Los datos provienen de sistemas transaccionales locales y registros de interacción (web/app) que alimentan el ecosistema analítico.

Data Layer: Centralización en Azure SQL Database con un modelo relacional normalizado para garantizar integridad y consulta eficiente.

Application Layer: Power Apps para la captura y gestión operativa de clientes, productos y ventas.

ETL Layer: Dataflows y Pipelines en Microsoft Fabric para extracción, transformación y carga, complementados con Notebooks Python para validaciones y cálculos avanzados.

Data Warehouse Layer: Fabric Data Warehouse como repositorio analítico optimizado para consultas y modelado dimensional.

Presentation Layer: Power BI para la construcción de dashboards interactivos y reportes ejecutivos.

User Access: Accesos y roles controlados que permiten la distribución segura de la información a los usuarios adecuados.

Capa de Datos

La capa de datos en Azure SQL está diseñada para soportar la gestión operativa y analítica del negocio. Se modelaron tablas maestras y transaccionales que permiten trazabilidad completa desde la venta hasta el pago y envío.

  • Ventas: Registro de transacciones con detalle de productos, cantidades, precio y fecha.
  • Usuarios: Información personal y de contacto de los clientes, incluyendo canales de registro.
  • Productos: Catálogo con descripción, precio, stock, marca, categoría y proveedor.
  • Pagos: Registro de medios de pago, montos, fechas y estado de cobro.
  • Envíos: Información logística con fechas estimadas y reales, estado y costo.
  • Carrito de compras: Estado y detalle de items antes de la compra final.
  • Canales y Visitas: Seguimiento del comportamiento digital para análisis de origen y uso.

Modelo relacional que muestra las entidades principales y sus relaciones para soportar informes y consultas analíticas.

Capa de Aplicación

Se desarrollaron aplicaciones en Power Apps para la captura y gestión de los procesos operativos: registro de ventas, mantenimiento de catálogo de productos y gestión de clientes, con pantallas intuitivas y controles para las operaciones diarias.

Diagrama de Flujo de la Aplicación

Flujo desde el inicio de sesión hasta las acciones sobre Productos, Clientes y Ventas. Incluye validaciones y rutas según si el cliente ya está registrado y si corresponde registrar pago o envío.

Pantalla Principal

Pantalla de entrada con tres accesos directos a las áreas: Gestión de Productos, Gestión de Clientes y Gestión de Ventas. Diseñada para facilitar la navegación y la rapidez de acceso.

Gestión de Productos

Permite mantener el catálogo con ID, nombre, descripción, precio, stock, categoría, marca y proveedor. Incluye funciones para crear, editar y eliminar productos y una barra de búsqueda para localizar ítems rápidamente.

Gestión de Clientes

Pantalla para administrar clientes: lista de clientes con identificador, nombre y correo, vista detallada del cliente seleccionado, y acciones de edición, eliminación y creación de nuevos registros. Incluye búsqueda rápida por nombre o ID.

Gestión de Ventas

Proceso que abarca selección de cliente, adición de productos, registro de pago y gestión de envío. Ofrece ventanas emergentes para seleccionar cliente y productos, y control de la transacción completa.

Seleccionar Cliente (Ventas)

Ventana emergente para buscar y seleccionar clientes por nombre o ID, con botón para agregar nuevo cliente si no figura en el registro.

Seleccionar Producto (Ventas)

Ventana emergente para búsqueda y selección de productos por nombre o ID, con información de precio y stock.

Gestión de Pagos

Pantalla para registrar pagos asociados a una venta: tabla de pagos (ID, fecha, medio, estado, monto), botones para agregar, editar y eliminar pagos, y cálculo del total pagado.

Gestión de Envíos

Pantalla para administrar envíos con detalle de fechas, estado, costo y opciones para agregar o modificar registros de envío asociados a cada venta.

Capa de Extracción, Transformación y Carga (ETL)

La orquestación ETL se implementó con Microsoft Fabric Data Factory. Los pipelines automatizan la extracción de las tablas transaccionales, la transformación (limpieza y estandarización) mediante Dataflows y la carga hacia el Data Warehouse. Notebooks en Python se usan para validaciones y cálculos de KPIs.

Flujo de Datos ETL

Origen de datos desde la aplicación, transformación y carga estructurada en tablas intermedias para su posterior modelado en el Data Warehouse.

Pipeline ETL - Vista General

Vista del pipeline que orquesta los pasos de extracción, transformación y carga, garantizando latencia y consistencia de la información.

Pipeline ETL - Transformaciones

Detalle de las transformaciones: limpieza, merge, standardization y enriquecimiento de atributos para preparar el dato para análisis.

Pipeline ETL - Validaciones

Controles de calidad y validaciones que aseguran integridad y consistencia antes de cargar al Data Warehouse.

Pipeline ETL - Completo

Visión integral del pipeline que automatiza la ingestión y preparación de datos para análisis.

Notebook Python - Extracción

Notebooks que realizan consultas, transformaciones y cálculos complementarios, además de preparar datasets para KPIs.

Notebook Python - Transformación

Ejemplos de transformaciones y cálculos realizados en Python para extender la lógica ETL y generar métricas avanzadas.

Sistema de Notificaciones

Notificaciones automatizadas que envían resultados y alertas a responsables mediante correos electrónicos.
Microsoft Fabric Data Factory Python Jupyter Notebooks

Capa de Almacén de Datos

El Fabric Data Warehouse funciona como el repositorio analítico central. Los datos transformados son modelados en esquemas dimensionales para facilitar consultas analíticas y la construcción de medidas en Power BI. Power Automate aporta automatización adicional (reportes programados y alertas).

Arquitectura del Data Warehouse

Modelo dimensional y semántico que soporta consultas eficientes y una capa analítica para Power BI.

Flujo de Automatización 1 - Reporte PBI Diario

Flujo programado que exporta un reporte de Power BI a PDF y lo envía por correo diariamente, asegurando la disponibilidad de información para stakeholders.

Flujo de Automatización 1 - Configuración Detallada

Detalle de las conexiones y pasos del flujo que generan y entregan el reporte automáticamente.

Flujo de Automatización 2 - Alerta Stock

Flujo que detecta niveles de stock críticos y envía alertas proactivas a responsables para reabastecimiento.

Flujo de Automatización 2 - Configuración Detallada

Configuración del trigger, condiciones y acciones que componen la automatización de alertas.

Capa de Presentación

En la capa de presentación se construyeron dashboards interactivos en Power BI que permiten explorar KPIs, tendencias y métricas operativas para la toma de decisiones. Los reportes combinan visualizaciones agregadas y detalles transaccionales para distintos perfiles de usuario.

Dashboard Principal

Vista ejecutiva con KPIs de ventas, conversión, y métricas de operación para seguimiento diario.

Indicadores de Rendimiento

Panel con métricas críticas: ventas por día, ticket promedio, tasa de conversión y stock crítico.

Reportes Analíticos

Reportes para análisis multidimensional y segmentación por canal, categoría y comportamiento del cliente.

Centro de Negocios

Hub central que consolida la información estratégica para la operación y dirección.

Dashboard Ejecutivo

Visión de alto nivel orientada a la toma de decisiones estratégicas.

Conclusiones

La implementación del ecosistema analítico integral para Mundo de Patas demuestra la convergencia efectiva entre tecnologías cloud y herramientas de la Power Platform para transformar procesos operativos y de análisis.

  • Optimización operativa mediante automatización de procesos de ventas, pagos y envíos.
  • Mejora en la calidad y consistencia de la información con un modelo de datos estructurado en Azure SQL y Fabric Warehouse.
  • Disponibilidad de insights y dashboards en tiempo real para la toma de decisiones.
  • Escalabilidad y sostenibilidad en la arquitectura para soportar crecimiento de datos y usuarios.
  • Automatización inteligente con Power Automate para alertas y distribución de reportes.

Esta solución no solo responde a una necesidad académica, sino que evidencia la aplicabilidad de soluciones BI en escenarios reales de e-commerce, estableciendo una base para mejoras continuas y futuros desarrollos.
